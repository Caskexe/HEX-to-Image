How to Use

HEX/Image turns a colour code into an image file. Everything runs in your browser and nothing is uploaded anywhere.

Choosing a colour

Type a hex code into the field, click the square chip to open your system colour picker, or press Shuffle for a random colour. In Chrome and Edge, Pick from screen lets you sample any pixel on your display. Short codes such as #F55 are expanded automatically, and 8-digit codes such as #FA525280 add transparency. Click any of the HEX, RGB or HSL readouts to copy that value.

The contrast rows show how the colour performs as text on white and on black, rated against WCAG guidelines. The strip below offers tints, shades and the complementary colour. Click a chip to switch to it.

Solid or gradient

Gradient mode adds an end colour and an angle. An angle of 0° runs bottom to top and 90° runs left to right, matching CSS. Swap colours reverses the direction without retyping anything.

Size and finish

Pick a preset or enter any size up to 8192 px on each side. The arrow button swaps width and height, and Lock aspect ratio keeps the proportions while you resize. Corner radius rounds the edges, up to a full circle or pill at 50%. The label option prints the hex code across the image in a colour chosen for legibility.

Saving

PNG keeps transparency and exact colour. JPEG and WebP produce smaller files and use the quality slider. JPEG cannot store transparency, so rounded corners are filled with white. Files are named from the prefix, the hex code and the size, for example brand-FA5252-1080x1080.png. Copy image places a PNG on the clipboard for pasting straight into other apps.

Batch

Paste a whole palette into the Batch tab to render every colour at once and download them together as a single ZIP file. Batch swatches use the size, finish and output settings from the Generate tab with a solid fill. Click any tile to open that colour in the Generate tab.

History

Every download from the Generate tab is logged with its settings. Load restores those settings exactly, so a past swatch can be re-exported or tweaked. History is stored in this browser and can be cleared at any time.
